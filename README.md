This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) for Google Developer Groups on Campus (GDGoC) Universitas Gadjah Mada 2026/2027.

This project is a modern, responsive web application built based on the official GDGoC Figma design tokens and dynamically integrates data from the GDGoC REST API with strict TypeScript typing and custom state management.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
